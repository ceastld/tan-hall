# 弹堂 · TAN HALL

原创回合制弹道对决。看风、测距、拉角蓄力，用殿术改站位，把对面从石殿上轰下去。

玩：https://ceastld.github.io/tan-hall/

系统向 TNT / 弹弹堂 / Gunbound / Worms 这一路对齐，角色、武器、道具、地图名字全部自写。

- 岚丸（青）vs 烬丸（洋红）
- 1 格 = 48px，满屏 20 格
- 65° 最远（角 = 65 ± 2×风），90° 高抛
- 体力 + 飞步 / 影挪 / 霓弹 / 鼓息 / 殿破
- 演习场对表
- v0.3：镜头跟弹、三裂、风柱 / 碎桥、埋了、瞄准建议行

主研发仓。百戏里的 `playbox/g/tan-tang` 是早期切片，以本仓为准。

## 本地

直接打开 `index.html`，或任意静态服务器。无构建、无 CDN。
